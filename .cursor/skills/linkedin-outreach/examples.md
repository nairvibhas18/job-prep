# Connection note examples

Count every character (spaces, punctuation, newlines). Cap is 300. These notes are single paragraph, no trailing newline in the count.

## Gold — IC (connection request; tenure 6 months–2 years)

**Chars: 290**

```
Hi Garvit, I'm Vibhas! I saw that you're a Software Engineer at Waymo, working on Onboard Compute Infra. I'm interested in autonomy infra and in your Bazel/CI work for the stack, and would love to know more about your work at Waymo. Would you be open to a brief chat about your experiences?
```

Hook is from **their** Experience (Onboard Compute Infra, Bazel/CI), not the JD team name. Converted intern in the 6–24 month window uses this same shape. Shorten `{role}` if the note would exceed 300.

Dossier lines (not in the 300-char note): `- Profile: https://www.linkedin.com/in/garvit-example/` and `- Tenure: 1 yr 4 mos`

Chat must paste that URL next to their name.

## Gold — Recruiter

**Chars: 258**

```
Hi Jim, I'm Vibhas! I saw that you're hiring for Data Infra intern at Flexport. I've worked on agent eval (Bedrock/Lambda) at Amazon, I'm interested in the intern role on that team, and I think I would be a great fit for this position. Would love to connect!
```

Role they are hiring for + one mapped experience + this posting. No resume URL.

Hi Maya, I'm Vibhas! I saw that you're hiring for ML intern at NVIDIA, working on Cosmos world models. I've worked on Amazon agent eval (Bedrock/Lambda), I'm interested in your world-model RL work, and I think I would be a great fit for this position. Would love to connect!

Recruiter spine plus **their** work (Cosmos / world-model RL). Not “advice navigating UNC.”

## Bad (do not write)

**JD-only hook** — fails the swap test:

```
Hey Garvit — Vibhas, UNC CS/Math (Dec '27). Came across your profile while researching Software Infra at Waymo. Would love to learn how you're approaching infra tooling there if you're open to connecting.
```

Any other Software Infra IC could replace Garvit. Use a noun from *their* bullets (sub-team, Bazel/CI, a named system) or skip.

**Tenure** — IC started 2 months ago, or 5 years on the team. Keep 6 months–2 years at this company.

**Too long** — Ajay’s full DM. Connection notes must truncate; put the long version only in a post-accept DM if asked.

**Referral ask** — “Would you be open to referring me?” ICs ask for a brief chat; recruiters/HMs ask to connect. Never a referral.

**UNC-only** — “Hey Sam, fellow Tar Heel — would love to connect.” Swap the name and it still works; skip or rewrite with a work hook.

**Type 2 opener** — “What should I study for the intern loop?” Homework ask. Not a connection note.

**Resume link** — “Here’s my resume: linkedin.com/in/vibhasn/.” Profile is enough; no URL in the note.

**Recruiter pitch to an IC** — highlight-reel credentials at an engineer. ICs get the profile-specific template.

**Invented profile URL** — do not guess `linkedin.com/in/firstname-lastname`. Copy the URL from the open profile tab.

**Senior Amazon** — “I’ve had over 5 years of technical experience.” Amazon is a finished internship.
